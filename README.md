# jena-heavy
Heavy-thinking mode for Jena (Saidie's AI). A small fast brain answers quick chat on her box; hard questions go to a
swarm of models that answer in parallel, and a judge model compares them and writes one final answer (the same idea as
"Heavy" multi-agent modes). This repo holds only code. Requests and answers travel through a private data store and
are never printed in the logs.
